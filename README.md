# Telegram feedback bot

Простой бот для обратной связи: пользователь пишет сообщение в Telegram, а оно приходит вам в личку.

## Что умеет

- принимает текст
- принимает фото, документы, видео, аудио, голосовые сообщения и стикеры
- пересылает содержимое админу вместе с данными отправителя

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой `ADMIN_CHAT_ID`. Проще всего написать боту `@userinfobot` или использовать личный тестовый скрипт.
3. Скопируйте `.env.example` в `.env` и заполните значения:

```env
BOT_TOKEN=...
ADMIN_CHAT_ID=...
```

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

## Как работает

- пользователь пишет боту в личку
- бот отправляет сообщение на указанный `ADMIN_CHAT_ID`
- пользователь получает ответ "Спасибо! Сообщение отправлено."
